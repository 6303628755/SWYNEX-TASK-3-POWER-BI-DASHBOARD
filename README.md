## Project Overview
An interactive Power BI dashboard developed as part of the SWYNEX Data Analyst Internship.

## Tools Used
- Microsoft Power BI Desktop
- Student Performance Dataset

## Dashboard Features
- Student count by GradeClass
- Average GPA by Gender
- Average GPA by Weekly Study Time
- Interactive Gender and GradeClass slicers
